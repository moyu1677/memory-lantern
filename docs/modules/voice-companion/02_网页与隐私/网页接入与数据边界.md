# 网页接入与数据边界

## 家人端：已授权声音库

页面：登录后从家人端工作台进入 `/voice-profiles`

家人只需要完成以下操作：

1. 填写声音名称；
2. 直接录音或上传音频文件；
3. 勾选授权说明；
4. 保存；
5. 在声音库中试听、设为当前或删除。

家人端不包含老人语音转写、情绪选择器或无关设置。这样它只承担“为已绑定老人管理授权声音”这一件事。

## 老人端：语音对话

页面：登录后从老人端工作台进入 `/assistant`

```text
录音 / 上传一段老人语音
    ↓
页面显示 ASR 转写，便于核对
    ↓
AI 生成陪伴回答
    ↓
自动播放家人音色的回答
```

文字转写显示在老人端，是为了核对老人输入；家人声音库不做这项转写。

## 保存什么

| 数据 | 保存位置 | 用途 |
| --- | --- | --- |
| 声音名称、远端 `voice_id`、当前状态 | 本地声音库 | 管理当前使用的家人音色 |
| 家人参考音频 | 受控远端语音服务器 | IndexTTS2 声音克隆 |
| 老人本轮 ASR 文本、短期会话状态 | 服务运行期 | 生成本轮对话 |

## 不保存或不展示什么

| 数据 | 处理方式 |
| --- | --- |
| 家人录音的转写内容 | 不生成、不保存、不展示 |
| 原始家人参考音频的本地副本 | 不写入项目目录 |
| 后端语气标签 | 不展示给老人，也不要求家人选择 |

删除声音时，系统同步请求远端删除对应声源。声音使用须以声音所有者明确授权为前提。
