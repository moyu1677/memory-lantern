# 输入输出与语气选择

## 主链路

```text
家人一次性录入已授权声音
    ↓
远端 IndexTTS2 服务保存参考音频，项目只保存受控 voice_id

老人说话
    ↓
ASR 返回文字
    ↓
AI 根据上下文生成一条陪伴回复，同时为“这条回复”选择语气
    ↓
IndexTTS2 按当前家人 voice_id 合成 WAV
    ↓
网页播放 AI 回答
```

## 语气选择的规则

语气不是从家人录音中识别出来的，也不由老人手动选择。

生成回复时，模型只返回下面的内部结构：

```json
{
  "reply": "给老人看的自然回复",
  "tone": "neutral | positive | comfort | concern"
}
```

| 内部语气 | 适合的回复 | 表达原则 |
| --- | --- | --- |
| `neutral` | 普通聊天、信息不足 | 平稳自然 |
| `positive` | 好消息、团聚、真诚喜悦 | 轻微明朗，不兴奋夸张 |
| `comfort` | 难过、想念、孤单、失落 | 温和接住，不模仿哭腔 |
| `concern` | 疲惫、担心、不安 | 平静关切，不制造紧张 |

程序还会限制回复：不凭空补充事实，不把“想老伴”擅自判断为离世，不使用“天大的好事”等舞台化表达。语气标签不回传到老人端界面。

## 关键接口

| 接口 | 输入 | 输出 |
| --- | --- | --- |
| `POST /audio/recognize` | 老人录音 | 转写文字 |
| `POST /audio/chat` | 老人转写文字 | AI 回复、一次性语音回复令牌 |
| `POST /audio/synthesize` | 语音回复令牌 | `audio/wav` |
| `POST /audio/preview` | 已保存的声音编号 | 试听 WAV |

家人端录入声音不调用 `/audio/recognize`，只把授权音频送往远端声音服务。

## 设计边界

- 不把 AI 的语气选择做成给老人点击的控件；
- 不把家人录音内容转写、展示或作为情绪判断依据；
- 不在本地项目目录保存原始参考音频；
- 若远端语音服务不可用，网页明确返回错误，不伪造音频结果。
