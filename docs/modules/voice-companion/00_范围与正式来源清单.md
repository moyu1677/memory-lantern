# 范围与正式来源清单

## 模块范围

本模块包含：

- 家人授权声音的录入、试听、切换与撤回；
- 老人端连续语音输入与 ASR；
- 陪伴回复生成；
- 根据**AI 已生成的回复**私下决定平稳、明朗、安抚或关切语气；
- IndexTTS2 声音克隆与 WAV 输出；
- 本地网页与远端 ASR / TTS 服务的安全连接。

本模块不包含：聊天关怀报告、MoCA、认知报告、知识库、成语游戏、账号体系或其他页面功能。

## 正式运行来源

| 正式文件 | 本模块职责 | 为什么不移动 |
| --- | --- | --- |
| `app.py` | 家人端、老人端和 `/audio/*` 路由；回复与语气选择 | 全站共享入口，移动会影响其他模块 |
| `database.py` | 家人声音库记录、当前声音状态 | 全站共享数据库连接与表管理 |
| `templates/audio_demo_family.html` | 家人端最小声音库页面 | Flask 正式模板目录 |
| `templates/index.html` | 老人端语音对话页面 | Flask 正式模板目录 |
| `asr_service.py` | 远端 ASR 客户端 | 正式运行依赖 |
| `voice_service.py` | 远端 IndexTTS2 客户端 | 正式运行依赖 |
| `remote_asr/` | GPU 服务器侧 ASR 服务 | 独立部署单元 |
| `remote_tts/` | GPU 服务器侧 IndexTTS2 服务 | 独立部署单元 |
| `run_voice_demo.ps1` | 本地网页、SSH 隧道与健康检查启动器 | 演示入口 |
| `tests/test_11_public_audio_demo.py` | 家人端 / 老人端语音链路回归测试 | pytest 正式目录 |
| `ASR_EVALUATION.md`、`evaluate_asr_fleurs.py` | 当前 ASR 公开基线与复现脚本 | 指标正式来源 |

## 未纳入的内容

| 文件或目录 | 实际用途 |
| --- | --- |
| `聊天关怀报告模块/`、`care_report_engine.py` | 聊天后的家人关怀提示 |
| `Moca模块/`、`questions.py`、`reports.py` | 认知测评与报告 |
| `rag.py`、`knowledge_seed.py` | 知识问答 |
| `idiom_game.py` | 成语互动 |

本目录只整理语音模块的阅读入口和边界，不移动以上文件，也不改变其逻辑。
