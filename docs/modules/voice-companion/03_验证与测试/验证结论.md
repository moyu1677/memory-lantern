# 验证结论

## 自动化回归

最近一次本地回归：`python -m pytest -q`

结果：**102 passed**。

与语音陪伴直接相关的覆盖包括：

- 老人、家人、社区和管理员均有受权限保护的登录入口；
- 家人端只可在绑定老人后管理声音库；
- 老人端保留 ASR、聊天和 WAV 合成接口；
- 家人授权音色可录入、试听、切换和删除；
- 回复生成后由回复内容选择内部语气；
- 空回复自动回退，不能发送静音回答；
- 语音合成令牌只能使用一次，返回 WAV 与时延头。

正式测试文件：`../../tests/test_26_voice_care_integration.py`、`../../tests/test_27_four_role_portals.py`。

## 已做的链路验收

本地网页通过受控 SSH 隧道连接远端 ASR 和 IndexTTS2 服务后，已验证：

```text
登录 → 四角色之一的授权工作台
家人 `/voice-profiles` → 老人 `/assistant`
老人语音转写 → `/voice/chat` → `/voice/synthesize` 返回有效 RIFF/WAV
```

情境测试中，好消息、失落和疲惫三类回复可分别选中明朗、安抚和关切内部语气；这些标签不会显示在网页中。

## 当前边界

- TTS 时延主要受远端 GPU 推理和文本长度影响；本模块没有通过删减回复内容来换取速度。
- 音色相似与语气自然度需在获得授权的真实家人参考音频上试听验收；自动化测试验证接口和控制逻辑，不替代人工听感评估。
- 语音对话用于陪伴，不作医疗诊断或紧急处置判断。
