# 运行说明

## 前置条件

- 本地项目虚拟环境已安装依赖；
- 远端 ASR 与 IndexTTS2 服务已启动且健康；
- SSH 配置中已有可用的服务器别名；
- 对话模型密钥和远端语音服务凭证只保存在运行环境，不提交到仓库。

## 启动本地演示

在项目根目录执行：

```powershell
.\run_voice_demo.ps1
```

默认读取项目自己的 `.venv\Scripts\python.exe`。如果团队成员已在另一个受控环境中安装依赖，可在当前 PowerShell 会话设置 `MEMORY_LANTERN_PYTHON` 为该解释器绝对路径；该变量只影响本次启动，不写入仓库。

脚本会：

1. 读取本地运行时密钥；
2. 建立到远端 TTS 与 ASR 服务的受控 SSH 隧道；
3. 检查两项远端服务健康状态；
4. 启动本地 Flask 网页；
5. 打开项目统一登录页；账户类型在注册时确定，登录后系统自动进入对应工作台。

常用页面：

```text
http://127.0.0.1:5000/login            四角色登录入口
http://127.0.0.1:5000/voice-profiles   已登录家人端声音库
http://127.0.0.1:5000/assistant        已登录老人端语音对话
```

## 服务职责

| 组件 | 职责 | 正式文件 |
| --- | --- | --- |
| 本地 Flask | 网页、会话和接口编排 | `app.py` |
| ASR 服务 | 老人语音转文字 | `remote_asr/`、`asr_service.py` |
| IndexTTS2 服务 | 声音录入、克隆和 WAV 合成 | `remote_tts/`、`voice_service.py` |
| 启动器 | 隧道、健康检查、环境变量注入 | `run_voice_demo.ps1` |

## 安全要求

- 远端 ASR / TTS 端口仅监听本机回环地址，经 SSH 隧道访问；
- 不把 `.env`、密钥文本、授权录音或生成音频提交到 Git；
- 服务器侧部署详情见正式文件 `../../remote_tts/README.md`；
- 训练任务与语音推理应使用明确的 GPU 资源隔离策略，避免同时抢占同一张卡。
