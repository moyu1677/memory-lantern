# 语音陪伴模块：展示讲解

## 一句话介绍

老人不需要看小字或打字，只要自然说话；系统把话听懂后生成陪伴回复，再用已授权的家人音色说出来。

## 可以这样讲

“家人只需一次性录入并授权自己的声音。老人端像普通聊天一样说话，系统先把语音转成文字，再由 AI 组织一段自然、克制的回复。AI 会在后端根据这段回复本身决定应当平稳、关切、安抚还是略带喜悦，但老人不需要设置这些参数。最后，IndexTTS2 使用已授权的家人音色把回复读出来。”

## 演示顺序

1. 打开家人端，录入或上传一段家人声音；
2. 点击试听，确认音色；
3. 设为当前声音；
4. 进入老人端，录一段自然提问或上传 WAV；
5. 展示 ASR 文字、AI 回复文字和自动播放的语音。

## 现场应强调的四点

1. **最小家人端：** 只做授权声音管理，没有无关设置。
2. **自然输入：** 老人说话即可，保留文字核对。
3. **语气在后端：** 根据 AI 的回复自动决定，不要求老人操作。
4. **授权与撤回：** 家人声音只用于该陪伴功能，删除时同步撤回远端声源。

## 不应夸大的说法

- 不把语音语气说成可以读取或诊断老人的真实心理状态；
- 不把当前 ASR 基线说成公开榜单 SOTA；
- 不把陪伴回答说成医疗建议、诊断或家人的替代品。
