# 语音陪伴模块

这是“忆路明灯”中负责**老人语音对话、家人声音录入与 AI 语音回复**的集中说明目录。

它只回答一件事：老人开口说话后，系统如何把语音转成文字、生成陪伴回复，再用已授权的家人音色说出来。

## 先看这四件事

1. [01_核心链路/输入输出与语气选择.md](01_核心链路/输入输出与语气选择.md)：整条语音链路、输入输出和后端语气选择。
2. [02_网页与隐私/网页接入与数据边界.md](02_网页与隐私/网页接入与数据边界.md)：家人端、老人端分别做什么，以及保存什么。
3. [03_验证与测试/验证结论.md](03_验证与测试/验证结论.md)：已完成的自动化验证、ASR 基线与当前边界。
4. [04_部署与运行/运行说明.md](04_部署与运行/运行说明.md)：本地网页与远端 ASR / IndexTTS2 服务如何启动。

## 一句话流程

```text
老人说话 → ASR 转文字 → AI 生成回复并私下选择语气 → IndexTTS2 用家人音色合成 → 老人听到回答
```

家人端刻意保持最小化：只录入、上传、试听、切换和删除声音；不转写家人录音，也不展示或要求选择 AI 的回答情绪。

## 为什么这里以说明和来源清单为主

`app.py`、`database.py`、正式模板和测试目录都是整站正在运行的共享文件。为避免出现两份逐渐不一致的语音代码，本目录不复制或移动它们，而是明确列出正式来源。这样既能独立讲清模块，也不会影响其他功能。
