# 聊天关怀报告模块：展示讲解

## 一句话介绍

当老人没有人陪伴时，可以自然地和 AI 聊天；系统不会把聊天记录直接交给家人，而是只整理少量“值得家人主动关心”的线索，给出一项温和、具体的联系建议。

## 可以这样讲

“我们不要求老人填问卷，也不要求老人逐条确认需求。老人只需要像平时一样聊天。系统只从老人和 AI 的聊天中，整理陪伴或日常生活上的潜在线索。家人最终不会看到聊天原话，而是看到一条简短的提醒，例如：最近可以主动问问老人是否需要一起处理一件生活事务。这个提醒不是诊断，也不是替家人做决定，而是帮助家人更快开始一次真实的关心。”

## 适合放在 PPT 的四点

1. **自然输入：** 老人说话即可，不增加答题或确认负担。
2. **有限提取：** 只关注“心理与陪伴”“生活与身体”两类关怀线索。
3. **家人可行动：** 输出一条概括和一项具体建议，而不是长篇聊天摘要。
4. **安全克制：** 不展示原话、不做疾病诊断；信息不足时明确说“暂不形成提示”。

## 一个展示例子

```text
本周值得留意：老人近期可能更希望在生活事务上得到分步协助。
关怀类别：生活与身体。
家人可以做：下次遇到表格、预约或缴费时，先问是否愿意一起确认步骤。
说明：这是一项关怀提示，不是医疗诊断。
```

## 现场演示顺序

1. 用老人账号完成 2 至 3 轮自然聊天；
2. 切换到已绑定的家人账号；
3. 打开“家庭关怀报告”，点击“根据近期聊天生成”；
4. 展示生成后的概括和建议；
5. 强调页面没有聊天原话，并展示“信息不足时暂不提示”的验证数据。
