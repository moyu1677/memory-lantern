# 聊天关怀报告模块

这是“忆路明灯”中**只负责老人—AI 聊天关怀提醒**的一套独立展示目录。

它回答的是：老人日常和 AI 聊天后，家人能否在不看聊天原话的前提下，得到一条简短、克制、可行动的关怀提示。

它**不包含 MoCA、认知分数、认知题目、语音识别、声音克隆、知识库或游戏**。这些内容仍属于项目的其他模块，不能和本模块混在一起解释。

## 先看这四件事

1. [聊天关怀报告模块最终说明.md](聊天关怀报告模块最终说明.md)：本模块的最终功能、真实测试结果、数据边界和展示说法。
2. [聊天关怀报告模块说明.md](聊天关怀报告模块说明.md)：早期的完整设计与文献说明；其中旧的 9 例结果已被最终说明中的 24 例最终实验取代。
2. [01_核心提取/care_report_engine.py](01_核心提取/care_report_engine.py)：模型如何提取信号，以及程序如何拦截风险内容。
3. [02_家人页面/family_briefs.html](02_家人页面/family_briefs.html)：家人最终会看到什么。
4. [03_验证与测试/验证结论.md](03_验证与测试/验证结论.md)：真实模型调用的结果、能力边界与复现方式。
5. [04_展示说明/模块讲解.md](04_展示说明/模块讲解.md)：适合向老师或队友说明本模块的非技术版讲法。

## 它在完整系统中的位置

```text
老人自然聊天
    ↓
只取老人说过的内容（不读取老人和家人的私聊）
    ↓
DeepSeek 结构化整理 + 程序安全校验
    ↓
家人主动点击生成报告
    ↓
一条概括提示 + 一项温和建议
```

## 重要说明

- 这个目录是为**展示、答辩和模块交接**准备的集中材料；原项目正在运行的正式文件仍在上一级目录，例如 `care_report_engine.py`、`app.py`、`database.py`。完整位置见 `00_范围与正式来源清单.md`。
- 为避免影响正在并行修改的语音功能，原代码没有被移动或改名。本目录不会单独启动网页；它把聊天关怀报告相关代码和说明集中展示出来。
- 任何页面展示都不应把模型输出说成疾病诊断，也不应承诺能发现老人所有真实需求。
