# 项目同步清单与边界

本仓库以远端 `main` 为基线，合并本地运行时、模块说明和可复用原型；不以旧目录覆盖已更新的多语言、绘图与界面功能。

## 已同步

- 主 Web 应用：认知测评、知识库、绘画、多语言、语音陪伴和家庭关怀报告。
- 语音链路：受授权声纹档案、远程 ASR/TTS、公开双页演示、短时一次性朗读令牌、粤语/潮汕话回退。
- 内容提取链路：显式同意后的需求卡、隐私受限的家庭报告、聚合验证页和测试夹具。
- 项目总设计与调研说明：见 [`project/`](project/)；模块级资料见 [`modules/`](modules/)。
- 独立的 GPU 语音原型：见 [`../prototypes/cross-language-voice-clone/`](../prototypes/cross-language-voice-clone/)。
- ASR 公开朗读语音的已发布聚合摘要：见 `tests/results/*_summary.json`。原始音频和逐条转写不入库。

## 明确不入库的本地材料

| 材料 | 原因 |
| --- | --- |
| `.env`、密钥文本/表格 | 机密信息；仓库只提供 `.env.example`。 |
| 真实录音、声纹样本、音频/视频输出 | 个人隐私与体积控制；服务端可按授权临时处理。 |
| SQLite 数据库、模型缓存、虚拟环境、`__pycache__` | 运行产物，可按说明重建。 |
| 原始评测 JSONL/逐条日志 | 可能含可识别文本且体积大；仅保留无敏感信息的聚合摘要。 |
| `ppt/`、`outputs/`、`模板/` 与 `网页端/` 展示素材 | 不属于产品运行时；`网页端` 三页为 PPT 静态展示板，不替换真实模板。 |
| `videolingo_indextts2/` | 上游 VideoLingo 的独立第三方项目；不复制进本仓库，避免将外部整仓库误作本项目源码。 |

## 运行前提

应用测试可在本机完成；真实 ASR/TTS 需要按 `docs/modules/voice-companion/04_部署与运行/运行说明.md` 在受控服务器配置 URL 与密钥。没有这些外部服务时，应用会给出可理解的配置错误，而不是提交密钥或伪造音频结果。
