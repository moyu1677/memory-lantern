# 普通话公开数据集测试说明

> **历史基准说明（2026-08-13）：** 本文保留的是旧版浏览器 Web Speech API 与腾讯云 ASR 的公开数据集测试记录，不能用于当前最终版的验收或部署。当前最终版所有语种的转写均使用受控远程 Whisper large-v3；请以根目录 `README.md`、`docs/项目配置与运行说明.md` 和 `tests/benchmarks/benchmark_04_mandarin_whisper.html` 为准。

## 1. 测试目标

本测试回答的是“项目的普通话语音转写接口在固定公开样本上的准确率和速度如何”，
不是训练认知障碍诊断模型，也不判断说话人是否存在认知障碍。

项目正式页面仍使用浏览器 Web Speech API 完成普通话输入。数据集基准测试为了
自动化和可重复性，经登录后调用项目 `/speech/recognize` 接口，并使用腾讯云
`16k_zh_en` 引擎。论文必须把这两条技术路径分别说明，不能把数据集结果写成
浏览器识别结果。

## 2. 推荐数据集

第一轮建议使用 Mozilla Data Collective 的 Common Voice Scripted Speech 26.0
Beijing Chinese 子集：

- 官方页面：<https://mozilladatacollective.com/datasets/cmruwsbag00c8md07lk1n7i1e>
- 格式：MP3、TSV；
- 大小约 113.39 MB；
- test 分区 170 条，可固定抽取 100 条；
- 许可页面标注 CC0-1.0，同时明确禁止尝试识别说话人身份。

如后续需要扩大测试，再考虑完整 Chinese (China) 数据集：

<https://mozilladatacollective.com/datasets/cmqim47x700tunq074za20dq1>

完整包体积很大，首轮没有必要下载。数据集下载、保存、使用和分享均应遵守其
页面当时显示的许可与限制。

## 3. 固定抽样规则

准备器默认采用随机种子 `20260806`，目标抽取 100 条：

| 分组 | 目标比例 | 用途 |
| --- | ---: | --- |
| 短句 | 30% | 基础指令和简短回答 |
| 中句 | 40% | 普通叙述句 |
| 长句 | 20% | 较长连续表达 |
| 数字/日期 | 10% | 检查时间、日期、数量词转写 |

如果某一组数量不足，脚本会从其他有效样本补齐，并在 `dataset_summary.json` 中
记录实际分组数量。每次论文复测应使用同一份清单、随机种子、代码版本和 ASR
引擎配置。

## 4. 结果字段

- `success`：接口成功且返回非空文字；
- `latency_s`：上传请求到收到完整响应的端到端时间；
- `raw_cer`：仅统一字符宽度并移除空白，保留标点差异；
- `normalized_cer`：进一步忽略标点、符号并统一“〇/零”；
- `audio_duration_ms`、`speech_duration_ms`、`pause_count`、`voiced_ratio`：
  当前规则式语音观测结果。

CER 越低越好。论文同时报告样本量、成功率、平均时延、P95 时延、原始 CER 和
基础规范化 CER，并人工抽查 CER 较高的样本。不能只展示最好的一批结果。

## 5. 运行顺序

1. 从官方页面下载并解压数据集；
2. 运行 `tests/datasets/prepare_mandarin_commonvoice.py`；
3. 启动项目，使用专门的老人端测试账号；
4. 运行 `tests/benchmarks/benchmark_11_mandarin_dataset.py`；
5. 运行 `tests/benchmarks/benchmark_12_summarize_mandarin_dataset.py`；
6. 将 `tests/results/mandarin_dataset_summary.md` 中的数据填写到论文；
7. 保存设备、网络、日期、代码提交号、引擎名称和数据集版本。

具体命令见 `tests/README.md`。

## 6. 研究边界

Common Voice 北京子集的年龄构成不代表老年群体，也不包含认知障碍临床标签。
因此它适合验证转写链路和测试程序，却不能用来训练或证明认知障碍识别模型。
下一阶段如开展老年人语音研究，需要伦理审批、知情同意、去标识化、专业人员
参与标注，并独立划分训练集、验证集和测试集。
