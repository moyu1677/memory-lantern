# 忆路明灯项目配置与运行说明

本文档供收到代码包的队员使用，目标是在一台新的 Windows 电脑上完成环境配置并运行项目。

> 项目涉及账号、认知测试结果和云服务密钥。请先阅读“打包与安全检查”，不要在群聊、截图或代码仓库中发送真实密钥。

## 1. 项目功能

当前项目包含：

- DeepSeek 智慧陪伴聊天；
- 普通话浏览器语音输入；
- 腾讯云粤语和潮汕话语音识别；
- 浏览器语音朗读；
- 按认知类型随机组卷的10题测试和固定规则评分；
- 适老化大字、大按钮界面；
- 账号注册、登录和退出；
- SQLite 用户及历史测试结果数据库；
- 根据总分和能力维度生成专属认知训练建议报告；
- 本地健康知识中心、关键词搜索、收藏和浏览器朗读；
- 社区知识投稿、管理员审核发布和报告关联阅读；
- 管理员用户管理、账号启停和密码重置。

认知测试结果仅供项目演示和初步参考，不构成医学诊断。

## 2. 运行环境

建议准备：

- Windows 10 或 Windows 11；
- Python 3.10 或更高版本；
- Microsoft Edge 或 Google Chrome 最新版；
- 可用的麦克风；
- 可访问 DeepSeek 和腾讯云的网络；
- DeepSeek API Key；
- 腾讯云 ASR AppID、SecretID 和 SecretKey。

项目目录已经包含 `ffmpeg.exe` 和 `ffprobe.exe`。如果代码包中没有这两个文件，需要自行安装 FFmpeg，并相应修改代码中的 FFmpeg 路径。

## 3. 安装 Python 依赖

在项目根目录打开 PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

如果 PowerShell 阻止激活虚拟环境，可以只在当前窗口临时允许脚本：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\.venv\Scripts\Activate.ps1
```

项目当前依赖包括：

- Flask
- openai
- python-dotenv
- websocket-client

SQLite、密码哈希和其他基础能力使用 Python 标准库或 Flask 自带组件，不需要额外安装数据库软件。

## 4. 创建环境配置文件

复制示例配置：

```powershell
Copy-Item .env.example .env
```

然后编辑项目根目录下的 `.env`：

```dotenv
DEEPSEEK_API_KEY=填写新的DeepSeek密钥
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-v4-flash

FLASK_SECRET_KEY=填写随机且保密的字符串
DATABASE_PATH=
SESSION_COOKIE_SECURE=false

TENCENT_ASR_APP_ID=填写腾讯云AppID
TENCENT_ASR_SECRET_ID=填写腾讯云SecretID
TENCENT_ASR_SECRET_KEY=填写腾讯云SecretKey

TENCENT_ASR_ENGINE=16k_zh_en
TENCENT_ASR_ENGINE_CHAOSHAN=16k_zh_en
TENCENT_ASR_ENGINE_CANTONESE=16k_yue
```

### 4.1 生成 Flask 密钥

可以使用下面的命令生成：

```powershell
python -c "import secrets; print(secrets.token_hex(32))"
```

把输出结果填写到 `FLASK_SECRET_KEY`。

每个队员应使用自己的本地 `.env`。不要把真实 `.env` 互相覆盖，也不要将其提交到 Git。

### 4.2 数据库路径

`DATABASE_PATH` 留空时，数据库自动创建在：

```text
data/memory_lantern.db
```

也可以填写绝对路径，将数据库放到其他位置。

公开注册可以选择老人端、家属端或社区端，任何公开注册账号都不会自动成为管理员。旧数据库中的后台管理员账号会继续保留。

不要通过复制数据库文件的方式合并不同队员的数据。SQLite 文件适合当前原型和单机演示，不适合多人同时写入的正式生产环境。

### 4.3 `SESSION_COOKIE_SECURE`

本地通过 `http://127.0.0.1:5000` 调试时保持：

```dotenv
SESSION_COOKIE_SECURE=false
```

正式部署到 HTTPS 后应改为：

```dotenv
SESSION_COOKIE_SECURE=true
```

## 5. 配置 DeepSeek

1. 在 DeepSeek 开放平台创建新的 API Key。
2. 将密钥填写到 `.env` 的 `DEEPSEEK_API_KEY`。
3. 确认账号有可用余额或额度。
4. 不要使用文档、聊天截图或其他队员曾公开发送过的旧密钥。

如果出现“未配置 `DEEPSEEK_API_KEY`”，请检查：

- `.env` 是否位于项目根目录；
- 变量名称是否拼写正确；
- 等号后是否真的有值；
- 修改后是否重启了 `app.py`。

## 6. 配置腾讯云语音识别

### 6.1 腾讯云控制台

需要完成：

1. 开通腾讯云语音识别 ASR；
2. 开通中国大陆实时语音识别；
3. 开发和演示阶段建议使用后付费；
4. 不需要开通跨境实时流量；
5. 在 API 密钥管理页面获取 AppID、SecretID、SecretKey；
6. 在费用中心设置预算提醒。

当前项目使用：

| 功能 | 引擎 |
| --- | --- |
| 潮汕话 | `16k_zh_en` |
| 粤语 | `16k_yue` |

潮汕话当前使用腾讯云大模型1.0混合方言引擎。接口已经验证可以真实调用，但对部分潮汕话说话人的识别错误率仍然较高，详见任务交接文档。

### 6.2 Edge 麦克风权限

1. 打开 `http://127.0.0.1:5000`；
2. 点击地址栏左侧的站点权限；
3. 将麦克风设置为“允许”；
4. 在 Windows 设置中选择真实物理麦克风；
5. 不要选择 ToDesk、网易等虚拟音频设备；
6. Windows 麦克风测试时，说话后音量必须明显变化。

如果出现“没有识别到清晰语音”，先检查录音是否为静音，不要先怀疑 API Key。

## 7. 启动项目

激活虚拟环境后运行：

```powershell
python app.py
```

浏览器打开：

```text
http://127.0.0.1:5000
```

第一次使用：

1. 点击“立即注册”；
2. 选择老人端、家属端或社区端；
3. 设置唯一账号和两次一致的密码；
4. 登录后进入对应角色的功能首页；
5. 老人端可以测试，家属端和社区端可以使用老人绑定码建立关联。

停止项目：

```text
Ctrl + C
```

## 8. 快速验收清单

### 8.1 账号

- 注册时两次密码不同会被拒绝；
- 重复账号名称会被拒绝；
- 密码至少8位，并同时包含英文字母和数字；
- 普通用户无法进入用户管理页面；
- 管理员可以启停普通用户和重置密码。

### 8.2 聊天

- 登录后进入“智慧陪伴”；
- 输入一条文字消息；
- DeepSeek 可以正常回复；
- 未登录时不能直接调用聊天接口。

### 8.3 语音

- 普通话浏览器识别可使用；
- 粤语选择后调用 `16k_yue`；
- 潮汕话选择后调用 `16k_zh_en`；
- 浏览器允许使用麦克风；
- 腾讯云控制台没有欠费或资源包耗尽提示。

### 8.4 认知测试与历史

- 完成全部10题；
- 测试结束后显示总分和各维度得分；
- “历史结果”页面出现本次记录；
- 可以进入“专属报告”，查看个性化训练卡、一周安排和安全提醒；
- 数据库中不保存原始语音和完整回答；
- 管理员可以查看其他用户的历史记录。

### 8.1 三类账户与老人绑定

公开注册可以选择：

- 老人端：进行认知测试并查看自己的结果；
- 家属端：使用老人提供的专属绑定码建立关联；
- 社区端：使用老人提供的专属绑定码建立关联。

系统不会再把第一个公开注册账户自动设为管理员。旧数据库中的管理员仍会保留后台权限，旧普通用户会自动迁移为老人端，并自动获得形如 `YL-ABCD2345` 的绑定码。

家属端和社区端只有在成功绑定老人后，才能查看该老人的历史结果与专属报告。只有共同绑定同一位老人的家属和社区账户才能互相留言。

绑定码属于访问授权凭据，只应提供给可信任的家属或社区工作人员。正式上线前建议补充绑定确认、撤销通知、访问审计和异常尝试频率限制。

### 8.2 老人端成语接龙小游戏

老人端首页和顶部导航包含“成语接龙”入口，支持：

- 键盘输入；
- 普通话浏览器语音识别；
- 腾讯云粤语识别；
- 腾讯云潮汕话识别；
- 语音识别文字确认后再提交；
- SQLite 本地成语库查询与提示；
- 电脑朗读当前成语；
- 正确回合统计，不采用扣分。

小游戏复用现有 `/speech/recognize` 接口，因此粤语和潮汕话仍需正确配置腾讯云密钥、FFmpeg 和麦克风权限。游戏只用于日常娱乐和语言练习，不属于认知测试，游戏回合不会写入认知测试历史记录。

项目随附 `data/idioms_seed.txt`，包含 29,536 条去重的四字成语。第一次启动或成语种子版本升级时，程序会自动导入 SQLite 的 `idioms` 表；重复启动不会重复插入。数据来源与 MIT 许可证见 `data/IDIOM_DATA_LICENSE.md`。

### 8.3 随机认知题库

`questions.py` 当前包含62道题目变体，每次测试按照固定配额生成10题：

| 能力维度 | 每次题数 | 最高分 |
| --- | ---: | ---: |
| 即时记忆 | 1 | 3 |
| 延迟记忆 | 1 | 3 |
| 时间定向 | 3 | 3 |
| 注意力 | 2 | 2 |
| 计算能力 | 1 | 1 |
| 语言能力 | 1 | 1 |
| 日常判断 | 1 | 1 |

即时记忆固定为第一题，延迟记忆固定为最后一题，并使用同一组随机词语；中间8题会随机排列。题目答案只保存在服务端，不会发送到浏览器。数据库仅保存本次题目 ID 和题库版本，不保存老人的完整回答。

扩充题库时必须维持每道题的难度大致相当，并由相关专业人员审核。当前题库和分数阈值仅用于项目原型，不能当作经过临床验证的诊断量表。

### 8.4 健康知识中心

所有登录用户都可以从首页或顶部“健康知识”进入知识中心：

- 老人端看到大字版生活支持、记忆练习和安全内容；
- 家属端额外看到家属照护内容；
- 社区端额外看到社区服务内容；
- 可按关键词和分类搜索，也可收藏文章；
- 文章详情可以调用浏览器文字转语音朗读；
- 专属测试报告按本次优先关注维度推荐相关文章。

社区端可以把本地经验先保存为草稿，再提交管理员审核。待审核、退回或停用文章不会对普通用户显示；只有管理员“通过并发布”后才进入知识中心。

首批 12 篇内置文章会在启动时自动写入 SQLite，内容和版本位于：

```text
knowledge_seed.py
```

文章正文、来源、审核状态和收藏分别保存在 `knowledge_articles` 与 `knowledge_favorites` 表。修改内置文章后应同步提高 `KNOWLEDGE_SEED_VERSION`，使已有数据库在下次启动时更新种子内容。

知识文章只用于健康教育。社区投稿不得包含可识别老人身份的信息，也不得给出诊断、处方、停药或更改剂量的指示。

### 8.5 知识库问答开关与 RAG 文档

智慧陪伴页在输入框上方提供“启用知识库回答”开关：

- 默认开启，并在当前浏览器中记住用户的选择；
- 开启时，只检索状态为 `published` 且当前账号角色有权查看的资料；
- 回答下方显示实际命中的标题、来源机构和来源链接；
- 没有足够相关资料时会明确提示知识库依据不足，不会让模型自行补充医学事实；
- 关闭时继续使用原来的 DeepSeek 陪伴聊天，不检索知识库，也不显示参考来源；
- 认知测试进行期间自动隐藏并停用该开关，知识库不会参与固定规则评分。

管理员登录后可从顶部导航进入“RAG文档”，或直接访问：

```text
http://127.0.0.1:5000/admin/rag-documents
```

后台支持上传 `.txt`、`.md`、`.docx` 和 `.pdf`。上传前应确认：

- 文档来自可信机构，来源名称和网页链接可核验；
- 文档不包含姓名、电话、地址、身份证号、原始录音或完整测试回答；
- 先保存为草稿进行人工检查，再发布；
- 扫描版 PDF 如果没有文字层将无法提取，需要先做 OCR；
- 加密 PDF、旧版 `.doc` 和超过系统限制的文档不会导入。

发布或停用文档后，程序会重建本地检索分块。当前版本使用中文关键词和字符片段的本地混合检索，不需要额外的向量模型密钥或向量数据库；DeepSeek 只负责依据命中的已审核片段组织回答。原始上传文件不会保留，提取后的正文、审核状态和分块存放在 SQLite 的 `knowledge_documents` 与 `knowledge_chunks` 表。

安装依赖时必须重新执行：

```powershell
python -m pip install -r requirements.txt
```

其中 `python-docx` 用于读取 `.docx`，`pypdf` 用于读取文本型 PDF。

## 9. 常见问题

### 9.1 腾讯云返回 4004

通常表示资源包或可用额度不足，需要开通对应的中国大陆后付费，或者购买正确的实时语音识别资源包。

### 9.2 潮汕话返回了文字，但错误较多

这不是密钥或网络问题，而是当前混合方言模型的准确率问题。暂时建议：

- 让用户靠近麦克风并完整说完一句话；
- 识别结果提交前由用户或家属确认；
- 后续对比腾讯云 `16k_zh_en_2.0`；
- 不要直接把认知测试正确答案设置成高权重热词，否则可能导致分数虚高。

### 9.3 修改代码后页面没有变化

先重启 Flask，然后在浏览器按：

```text
Ctrl + F5
```

### 9.4 数据库需要清空

先停止项目并备份数据库，再删除：

```text
data/memory_lantern.db
data/memory_lantern.db-wal
data/memory_lantern.db-shm
```

重新启动时会创建空数据库。此操作会永久删除用户和历史记录，不要在未备份的情况下执行。

## 11. 正式部署前必须处理

当前 `app.py` 使用 Flask 调试服务器：

```python
app.run(debug=True, port=5000)
```

它只适合本地开发。正式部署前需要：

- 关闭 `debug`；
- 使用 Waitress、Gunicorn 等生产 WSGI 服务；
- 使用 HTTPS；
- 将 `SESSION_COOKIE_SECURE` 设为 `true`；
- 使用 MySQL 或 PostgreSQL 替代单机 SQLite；
- 加入数据库迁移、备份和恢复流程；
- 加入登录频率限制和审计日志；
- 明确认知测试数据的授权、保留和删除规则。
- 为老人绑定加入本人确认或监护人授权流程；
- 为家属与社区留言加入删除、更正、导出和保存期限规则；
- 对绑定码验证、登录和留言接口加入频率限制与审计日志。
