# 忆路明灯最终版配置与使用说明

更新时间：2026-08-13
适用分支：`agent/final-memory-lantern`

本文档是当前最终版的唯一运行与使用说明。当前语音链路为 **受控远程 Whisper large-v3 + IndexTTS2**；浏览器只采集麦克风录音，**不使用浏览器语音识别，也不使用腾讯云 ASR**。

> 项目用于课程与创新实践演示，不是医疗器械。认知测试、语音表现统计、关怀提示和训练建议均不能用于疾病诊断、治疗或替代专业意见。

## 1. 最终版包含什么

- 老人端、家人端、社区端、管理员端四角色隔离；
- 老人端智慧陪伴聊天、语音输入、认知测试、历史结果、知识中心、成语接龙和绘图辅助评分；
- 家人端绑定老人、登记本人授权声音、试听、撤回授权和家庭关怀报告；
- 老人只可选择已绑定家人授权的声音；家人不能替老人切换声音；
- 普通话、粤语、潮汕话、英文统一由远程 Whisper large-v3 转写；
- 聊天回复及认知题朗读使用老人当前选中的同一条家人声音；英文也不更换为其他声音；
- 英文模式下，聊天回复、认知题和朗读均使用英文；
- 短录音补齐 Whisper 所需输入；超过 30 秒的录音使用连续长音频转写，不截掉后半段；
- 转写尽量保留“嗯、呃、啊”、重复和自我修正，聊天助手将其作为自然表达理解，不在回复中复述或评价。

## 2. 使用前准备

### 2.1 本机环境

需要：

- Windows 10/11；
- Python 3.10 或以上；
- 最新版 Edge 或 Chrome；
- 可用实体麦克风；
- PowerShell 和 SSH；
- FFmpeg：项目目录中的 `ffmpeg.exe` 或系统 `PATH` 中的 `ffmpeg`。

### 2.2 私有数据与密钥

以下内容只能保存在本机或受控服务器，严禁提交到 GitHub、聊天记录或截图：

- `.env`；
- DeepSeek API Key；
- ASR 与 IndexTTS2 服务密钥；
- SQLite 数据库及其 `-wal`、`-shm` 文件；
- 原始录音、声音样本、真实聊天和测试数据。

### 2.3 远程语音服务条件

完整语音模式依赖已受控的 GPU 主机：

| 服务 | 远程端口 | 作用 |
| --- | ---: | --- |
| IndexTTS2 | 5000 | 已授权家人声音朗读 |
| Whisper large-v3 | 8000 | 中文、方言和英文转写 |

本机 SSH 配置必须有可用的 `teacher-server` 别名，并有权连接该主机。`run_voice_demo.ps1` 会建立本地隧道、在内存中读取运行凭证并检查服务健康；浏览器不会获得 API Key。

远程 Whisper 服务的部署文件位于 `remote_asr/`。部署负责人应按 [remote_asr/README.md](../remote_asr/README.md) 配置模型路径和远程 `.env`，但不得把该 `.env` 上传到仓库。

## 3. 从 GitHub 获取并初始化

在 PowerShell 执行：

```powershell
git clone -b agent/final-memory-lantern https://github.com/moyu1677/memory-lantern.git
cd memory-lantern
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

首次克隆没有本地数据库时，创建空白 SQLite 数据库和基础知识数据：

```powershell
.\.venv\Scripts\python.exe -c "import app"
```

如果仅需可选的绘图机器辅助评分或本地语义评分，再安装：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-ml.txt
.\.venv\Scripts\python.exe scripts/download_semantic_model.py
```

## 4. 数据库、账号和密钥

### 4.1 新建演示数据库

新建数据库后，打开网站并按角色注册账号。密码至少 8 位，且必须同时包含英文字母和数字。公开注册账号不会成为管理员。

### 4.2 保留既有账号和声音库

既有账号、密码、绑定关系、已授权声音和历史记录都在私有 SQLite 数据库中。请保留原数据库到仓库外的位置，并在启动时明确指定：

```powershell
.\run_voice_demo.ps1 -DatabasePath "D:\private-data\memory_lantern.db"
```

不要复制、重命名或上传该数据库来“同步账号”。数据库被换成空白文件时，原登录信息自然不会存在。

### 4.3 DeepSeek 密钥

自动启动器在启动前读取当前 PowerShell 窗口中的 `DEEPSEEK_API_KEY`。首次运行可设置：

```powershell
$env:DEEPSEEK_API_KEY = "你的 DeepSeek 密钥"
```

`.env` 用于应用运行配置；请勿把真实值写进 `.env.example` 或任何文档。

## 5. 启动最终版

完整体验必须使用启动器：

```powershell
.\run_voice_demo.ps1
```

默认地址为：

```text
http://127.0.0.1:5000
```

如果端口已被占用：

```powershell
.\run_voice_demo.ps1 -AppPort 5055
```

然后打开 `http://127.0.0.1:5055`。

启动器成功后会同时确认网页、Whisper 和 IndexTTS2 可用。不要只执行 `python app.py` 来演示语音功能：这样可以打开页面，但不会自动建立受控语音隧道。

停止前台演示时按 `Ctrl + C`。如需仅开发页面或执行离线测试，可使用 `python app.py`，但此模式不应被当作完整语音演示。

## 6. 四角色实际使用顺序

### 6.1 老人端

1. 在登录页选择“老人端”，登录或注册。
2. 进入首页后打开“智慧陪伴”。
3. 在语言菜单选择自动识别、普通话、粤语、潮汕话或 English。
4. 点击“录音转文字”，说完后停止录音；系统先将文字放入输入框，老人可检查、修改或重新录音，再发送。
5. 点击“开始认知测试”可用语音或文字作答。选择 English 时题目、回复和朗读会切换为英文。
6. 在“选择陪伴声音”中选择已绑定家人授权的声音。选择后，聊天回复和认知题朗读使用这同一条声音。

### 6.2 家人端

1. 老人登录首页后取得自己的绑定码，仅交给可信家人。
2. 家人在登录页选择“家人端”登录或注册，使用绑定码与该老人建立关系。
3. 打开“声音库”，选择已绑定老人，录制或上传 10–30 秒本人明确授权的声音。
4. 核对 Whisper 转写内容并确认授权后，声音进入该老人的专属库。
5. 家人可以试听、继续添加或撤回自己授权的声音；家人端不会替老人选择当前使用声音。
6. 完成若干轮自然聊天后，可在“家庭关怀报告”生成汇总。报告仅使用经授权的稳定关怀信息，不展示原始聊天或录音。

### 6.3 社区端与管理员端

- 社区端只可在获得老人绑定授权后开展协作与服务支持；
- 管理员端用于账号启停、内容审核、知识库与研究管理；
- 四端不共享未授权数据；遇到 403 表示当前角色或绑定关系不具备权限。

## 7. 语音使用说明

### 7.1 转写

- 浏览器只录音，录音文件经 Flask 和 SSH 隧道提交给远程 Whisper large-v3；
- 可接受 WAV、MP3、M4A、WebM、OGG，单次不超过 20 MB；
- 手动录音后必须先查看文字，避免错误文字直接进入聊天或认知计分；
- 连续语音对话在明显停顿后自动结束本轮并发送；
- 识别质量仍受麦克风距离、环境噪声、说话音量、方言和音频是否真实录到影响。请优先靠近实体麦克风，关闭电视或其他外放声音。

### 7.2 家人声音朗读

- 仅使用已绑定且已授权的家人声音；
- 老人未选择任何家人声音时，系统不会伪装成家人声音；
- 中文、英文回复始终使用老人当前选定的同一条声音；
- 服务端根据最终回复自行处理朗读表现，使用者不需要、也不能上传或选择额外的表达样本。

### 7.3 麦克风权限

1. 在 Chrome 或 Edge 地址栏的站点权限中将“麦克风”设为允许；
2. 在 Windows 声音设置中选择真实实体麦克风，而不是远程桌面或虚拟音频设备；
3. 说话前检查 Windows 麦克风电平是否变化；
4. 更换权限或设备后刷新页面再录音。

## 8. 验收与常见问题

### 8.1 启动后先检查

- 登录页可打开；
- 选择角色后可注册或登录；
- 老人端可录音并在发送前看到转写；
- 家人端可完成声音登记、转写确认、授权和试听；
- 老人端可选择已授权家人声音；
- 英文录音后得到英文聊天回复和英文题目；
- 完成认知测试后可在历史中看到结果；
- 家人报告不显示原始聊天或录音。

### 8.2 常见报错

| 现象 | 检查方式 |
| --- | --- |
| `语音识别服务尚未连接` | 使用 `run_voice_demo.ps1` 启动；检查 `teacher-server` SSH 和远程 8000 服务。 |
| `没有识别到清晰的话语` | 检查浏览器和 Windows 麦克风权限、实体麦克风电平、距离和环境噪声。 |
| 登录后账号不存在 | 确认启动时使用的是原有私有数据库，而不是新的空白数据库。 |
| 家人看不到声音 | 确认家人与老人已绑定、声音已通过转写确认和授权，且当前登录的是对应老人账号。 |
| 英文题目或回复不正确 | 在智慧陪伴页语言菜单选择 English 后重新开始测试或录音。 |
| 页面显示旧内容 | 重启启动器，并在浏览器按 `Ctrl + F5`。 |
