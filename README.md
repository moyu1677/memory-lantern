# 💡 忆路明灯（Memory Lantern）

面向老年人的多方言智慧陪伴与认知表现辅助评估平台。

项目融合生活化认知问题、普通话/粤语/潮汕话语音交互、语音朗读、认知表现记录、
专属建议报告和健康知识库，为老人、家属与社区提供分角色的陪伴和信息协作能力。

> **重要声明：** 本项目是课程与创新实践原型，不是医疗器械或医疗用品。测试分数、
> 语音特征和训练建议仅供健康管理与项目体验参考，不能用于疾病诊断、治疗或替代医生意见。

## 主要技术

- **后端：** Python、Flask
- **前端：** Jinja2、HTML、CSS、JavaScript
- **数据库：** SQLite
- **大模型：** DeepSeek API
- **语音：** Web Speech API、腾讯云 ASR、浏览器 SpeechSynthesis
- **音频处理：** FFmpeg
- **知识库：** SQLite 内容库、中文关键词与字符片段混合检索
- **测试：** pytest

## 语音陪伴与聊天关怀报告模块

本分支同步了两项后端能力，并刻意未覆盖 UI、模板、样式、MoCA 或共享的 `app.py` / `database.py`，以避免与并行开发冲突：

- 语音陪伴：受控远端 ASR、已授权家人音色的 IndexTTS2 合成，以及独立的 GPU 服务部署文件；
- 聊天关怀报告：只依据老人端对话生成非诊断性的结构化关怀提示，拦截原话复述、无依据来源和不匹配的行动建议。

模块说明、环境变量与接入契约见 [模块交接说明](docs/modules/README.md)。UI 和数据库负责人可据此把页面、权限和持久化接入当前主分支，而无需复制或替换其共享文件。

## 快速开始

### 1. 获取代码

```powershell
git clone https://github.com/moyu1677/memory-lantern.git
cd memory-lantern
```

### 2. 创建虚拟环境并安装依赖

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

### 3. 配置本地环境变量

```powershell
Copy-Item .env.example .env
```

编辑 `.env`，填写各自的 DeepSeek 与腾讯云密钥。真实密钥只保存在本机，禁止提交到
GitHub、群聊或截图中。

### 4. 启动

```powershell
python app.py
```

浏览器访问：

```text
http://127.0.0.1:5000
```

更完整的安装、密钥、麦克风和常见问题说明见：
[项目配置与运行说明](docs/项目配置与运行说明.md)。

## 团队协作流程

### 开始开发前

```powershell
git switch main
git pull origin main
git switch -c feature/任务名称
```

建议分支示例：

- `feature/ui`：适老化界面与交互；
- `feature/voice`：语音识别、语音克隆与提示；
- `feature/testing`：自动化测试和实验数据；
- `feature/report`：测试报告和内容；
- `docs/presentation`：论文、PPT、海报和答辩材料。

### 完成开发后

```powershell
python -m pytest -c tests/pytest.ini -q
git status
git add 修改过的文件
git commit -m "feat: 简要说明本次改动"
git push -u origin feature/任务名称
```

然后在 GitHub 创建 Pull Request，请至少一名队友检查后再合并到 `main`。

### 提交信息建议

- `feat:` 新功能；
- `fix:` 修复问题；
- `test:` 新增或调整测试；
- `docs:` 文档、PPT或说明更新；
- `style:` 只调整界面样式；
- `refactor:` 重构代码但不改变功能。

## 每日进度同步规则

为了减少五个人同时修改造成的冲突，建议每天结束前完成：

1. 在群内发送“今天完成 / 尚未完成 / 明天计划 / 当前阻塞”；
2. 推送自己的功能分支，不把未完成代码直接推到 `main`；
3. Pull Request 中写清修改页面、接口、数据库和测试结果；
4. 合并后更新[任务交接与下一步计划](docs/项目任务交接与下一步计划.md)；
5. 其他队员第二天开始前先执行 `git pull origin main`；
6. 数据库文件、`.env`、录音和真实用户数据不通过 Git 同步。

Pull Request 描述可以使用下面的格式：

```markdown
## 本次完成

- 数据库：

- [ ] 未提交密钥、数据库或录音
```

## 安全与研究边界

- 禁止提交 `.env`、API Key、SQLite 数据库、原始录音和真实老人回答；
- 不要把认知测试正确答案设置成高权重语音热词；
- 语音行为特征只用于描述性研究，当前不参与14分评分；
- 评分标准是项目原型，不得宣传为 MoCA、MMSE 或临床诊断量表；
- 绘图机器结果是研究型辅助预测，未形成双人共识的数据不得进入训练集；
- 采集老人语音或测试数据前，应取得知情同意并规定删除时间；
- 正式上线前必须关闭 Flask Debug、启用 HTTPS、访问审计与备份恢复。
